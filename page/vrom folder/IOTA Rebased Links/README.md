# Wichtige Links zum IOTA-Rebased-Ökosystem

Stand der Linkprüfung: **12. Oktober 2026**.

Diese Sammlung umfasst IOTA L1 (Move), die separat gekennzeichnete IOTA EVM sowie Projekte, die IOTA-Technologie einsetzen. Eine erreichbare Website bestätigt weder eine funktionierende Anwendung noch eine aktuelle Mainnet-Integration. Testnet-Angebote und Ankündigungen sind deshalb separat aufgeführt. Details zu auffälligen und entfernten Links stehen im [Prüfprotokoll](LINK_AUDIT.md).

## Einstieg und Ökosystem

- [IOTA](https://www.iota.org/): offizieller Einstieg.
- [IOTA Registry](https://iota-registry.org/): Community-Verzeichnis von Projekten und Infrastruktur.

- [Starfish auf dem Mainnet](https://blog.iota.org/starfish-mainnet-release/): Informationen zum Konsens-Upgrade von 2026.
