Der [UN-Bericht](https://repository.unescap.org/items/05edcbec-b606-490a-938d-593c56dd25a3) schätzt, dass eine vollständige digitale Handelserleichterung die durchschnittlichen globalen Handelskosten um etwa elf Prozent senken könnte. Verifiable LEIs können nicht nur eine Organisation identifizieren, sondern auch nachweisbar machen, welche Person mit welcher Befugnis ein PDF oder einen anderen digitalen Inhalt für sie signiert hat. Solche überprüfbaren Unternehmensidentitäten ergänzen interoperable Handelsdokumente und sind deshalb auch für TWIN-nahe Prozesse interessant
